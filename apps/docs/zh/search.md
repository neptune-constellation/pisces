# 搜索与键盘

## 搜索如何工作

面板使用**基于键的前缀匹配** —— 不是模糊搜索。你的输入被解释为：

```text
位置键 + 代理键
```

1. pisces 找到能作为输入前缀的最长位置键。
2. 剩余字符作为前缀匹配代理键。
3. 如果没有位置键匹配，则整个输入只与代理键匹配（在*当前*目录启动代理）。

搜索不区分大小写；声明了多个键的条目，只要**任意一个**键满足规则即匹配。

### 示例

设位置键为 `b`，代理键为 `oc`（opencode）和 `cs`（crush）：

| 输入   | 结果                               |
| ------ | ---------------------------------- |
| （空） | 所有目录和仅代理条目（组合隐藏）   |
| `b`    | `b` 目录及其所有代理组合           |
| `bo`   | `b` 下代理键以 `o` 开头的组合      |
| `boc`  | 唯一的 `b` + opencode 组合         |
| `oc`   | 仅代理的 opencode 条目（当前目录） |
| `xyz`  | 无匹配                             |

## 面板条目

列表中出现三种类别：

- **📁 目录** —— 在配置的位置打开新终端。
- **📁 + ⚡ 组合** —— 在位置打开新终端*并*在那里运行代理。组合是位置 × 代理的笛卡尔积，仅在过滤时显示。
- **⚡ 代理** —— 在当前工作目录运行代理。

结果排序：目录优先，其次组合，最后是仅代理条目。

## 键盘快捷键

| 操作        | 按键                   |
| ----------- | ---------------------- |
| 向上导航    | `↑` 或 `Ctrl+K`        |
| 向下导航    | `↓` 或 `Ctrl+J`        |
| 选择 / 启动 | `Enter`                |
| 默认启动    | `Ctrl+D`（或 `Cmd+D`） |
| 退出        | `Esc` 或 `Ctrl+C`      |

`Ctrl+D` 启动[配置](./config#default)中的 `default` 路径和命令。
