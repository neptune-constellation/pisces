# 搜索与键盘

## 搜索如何工作

面板使用**基于键的前缀匹配** —— 不是模糊搜索。你的输入被解释为：

```text
位置键 + 代理键   （或 位置键 + 编辑器键）
```

1. pisces 找到能作为输入前缀的最长位置键。
2. 剩余字符作为前缀同时匹配代理键**和**编辑器键；两种匹配到的条目都会返回。
3. 如果没有位置键匹配，则整个输入只与代理键和编辑器键匹配（在*当前*目录启动）。

搜索不区分大小写；声明了多个键的条目，只要**任意一个**键满足规则即匹配。

### 示例

设位置键为 `b`，代理键为 `oc`（opencode）和 `cs`（crush），编辑器键为 `vscode`：

| 输入      | 结果                                       |
| --------- | ------------------------------------------ |
| （空）    | 所有目录、仅代理和仅编辑器条目（组合隐藏） |
| `b`       | `b` 目录及其所有代理和编辑器组合           |
| `bo`      | `b` 下代理键以 `o` 开头的组合              |
| `boc`     | 唯一的 `b` + opencode 组合                 |
| `bvscode` | 在 VS Code 中打开 `b` 目录                 |
| `oc`      | 仅代理的 opencode 条目（当前目录）         |
| `vscode`  | 仅编辑器的 VS Code 条目（当前目录）        |
| `xyz`     | 无匹配                                     |

## 面板条目

列表中出现四种类别：

- **📁 目录** —— 在配置的位置打开新终端。
- **📁 组合** —— 在位置打开新终端*并*在那里运行代理。组合是位置 × 代理的笛卡尔积，仅在过滤时显示。
- **💻 编辑器** —— 在 GUI 编辑器（如 VS Code）中打开位置（仅编辑器条目则为当前目录），不涉及终端。位置 × 编辑器的组合同样仅在过滤时显示。
- **🤖 代理** —— 在当前工作目录运行代理。

结果排序：目录优先，其次组合，最后是仅代理和仅编辑器条目。

## 键盘快捷键

| 操作        | 按键                   |
| ----------- | ---------------------- |
| 向上导航    | `↑` 或 `Ctrl+K`        |
| 向下导航    | `↓` 或 `Ctrl+J`        |
| 选择 / 启动 | `Enter`                |
| 默认启动    | `Ctrl+D`（或 `Cmd+D`） |
| 最近打开    | `Ctrl+R`（或 `Cmd+R`） |
| 退出        | `Esc` 或 `Ctrl+C`      |

`Ctrl+D` 启动[配置](./config#default)中的 `default` 路径和命令；未配置 `default` 时，改为打开一个空白终端窗口。

`Ctrl+R` 打开最近打开弹窗，列出你最近 10 次启动（代理、编辑器和目录）及其打开时间。使用 `↑`/`↓` 导航、`Enter` 重新启动；`Esc` 返回调色板。
