# 子目录浏览

有时候你想要的目录在某个已配置位置的下一级。与其把每个子目录都加进配置，不如在启动时直接浏览进去。

## 工作方式

输入位置键，后面跟 `/` 或 `\`。面板会从条目切换为该位置的**子目录**：

| 输入    | 结果                               |
| ------- | ---------------------------------- |
| `b/`    | 显示 key 为 `b` 的位置下所有子目录 |
| `b/pro` | 显示名称以 `pro` 开头的子目录      |
| `b\src` | 同上 —— `\` 同样可以作为分隔符使用 |

继续输入可按前缀过滤；按 `Enter` 在选中的子目录打开新终端。隐藏目录（以 `.` 开头的名称）会被排除。

## 这里没有代理组合 —— 这是刻意设计

子目录模式**只打开终端**，从不把子目录和代理组合。有些父目录包含几十个子目录，若把每个子目录都和所有已配置的代理组合，会产生选项的笛卡尔积 —— 列表会变得无法使用，而不是更方便。

选中子目录后，在新打开的终端里手动启动你的代理即可。
